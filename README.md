There are two models:

- model1.py is the work in progress and is the MAIN model which has the algorithm implemented from the paper;

- model2.py is the modified version of Andrej Karpathy's nanoGPT and DOES NOT INCLUDE the algorithm from the paper AND is used to test what works for the pathfinder task;

---------------------
Usage:

1. Download the preprocessed pathfinder data from this link:
   https://huggingface.co/datasets/TitasB/LRA/resolve/main/lra_pathfinder_preprocessed.7z
   
2. Download the requirements (excluded PyTorch 2.5.1+cu121);

3. Run the selected Training module;
